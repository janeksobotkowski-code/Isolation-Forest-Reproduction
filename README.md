# Isolation-Forest-Reproduction
Reproducing iForest based on Liu et al., 2008

## Contents
* `isolation_forest_reproduction.ipynb`: Self-contained implementation 
* `roc_curves_reproduction.png`:  ROC curves 

## Results Summary (10 Trials)
* **Breastw**: Paper AUC = 0.99 | Reproduced AUC = 0.9881 ± 0.0012
* **Ionosphere**: Paper AUC = 0.85 | Reproduced AUC = 0.8555 ± 0.0059
* **Pima**: Paper AUC = 0.67 | Reproduced AUC = 0.6828 ± 0.0103
